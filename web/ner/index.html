      NER review

      Two screens over the rule output of register.py and link.py. Every action is saved immediately: entry decisions go to data/register/*.json, mention decisions to data/ner/<vol>-decisions.json. Reruns of the scripts keep them.

      Register

      • 1–9 choose that Wikidata candidate · Enter confirm the automatic match · 0 checked, no Wikidata match · X reject (not a person/place)
      • J/K next/previous entry · / filter · S search Wikidata with another name
      • Merge into…: the entry is the same as another; its mentions follow on the next link.py run.
      • Split: tick mentions in the list and move them to another entry or a new one.

      Mentions

      • Groups are ambiguous mentions with the same candidates in one chapter. The rule's guess is pre-selected.
      • ↓/↑ next/previous mention · Enter accept the guess · 1–9 that candidate · X not a name · U undo the decision
      • Shift+1–9 or all open →: the rest of the group to one candidate · Shift+Enter accept all open guesses
      • Space show the scan · P the whole paragraph, where you can select a name the model missed and add it

      Afterwards

      Nothing changes in the TEI until you rebuild:

      cd scripts && $P link.py --vol 1932 && cd ..
$P scripts/to_tei.py --vol 1932 --validate && $P scripts/build_site.py
